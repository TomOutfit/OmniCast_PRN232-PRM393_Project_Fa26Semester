# OmniCast - Quick Start Guide

**Project:** OmniCast Enterprise Media & Broadcast Intelligence Network  
**Version:** 5.0  
**Estimated Time:** 5-10 minutes to first EPG view

---

## 🚀 3-Minute Quick Start

### Step 1: Access OmniCast
```
🌐 Web: https://omnicast.vercel.app
📱 Mobile: Download APK from [link]
```

### Step 2: Create Account
```
1. Click "Đăng ký" / "Sign Up"
2. Enter: Email, Password, Name
3. Click "Tạo tài khoản"
4. You're in! 🎉
```

### Step 3: Explore EPG
```
1. On dashboard, see today's schedule
2. Click any program for details
3. Add to Watchlist (❤️ icon)
4. Enable notifications
```

**That's it!** You're ready to use OmniCast.

## ⚡ Quick Task Reference

### Task 1: Find "Running Man" episode tonight
```
1. Press Ctrl+K (or click 🔍)
2. Type "Running Man"
3. Filter: Tonight
4. Click result > Add to Watchlist ❤️
```

### Task 2: Set reminder for favorite show
```
1. Find show in EPG
2. Click ❤️ to add Watchlist
3. Go to Settings > Notifications
4. Enable "Program Start" alert
5. Set reminder time: 15 minutes
```

### Task 3: Browse channel schedule
```
1. Click "Kênh" tab
2. Select channel (e.g., VTV3)
3. View 24-hour schedule
4. Click any program for details
```

### Task 4: Use advanced search
```
1. Click 🔍 icon
2. Click "Bộ lọc" / "Filters"
3. Set criteria:
   - Thể loại: Drama
   - Ngày: 2026-09-11
   - Giờ: 20:00 - 23:00
   - Độ tuổi: 16+
4. Click "Tìm kiếm"
```

### Task 5: Manage notifications (Mobile)
```
1. Open app > Settings ⚙️
2. Notifications
3. Enable: Program Start Alert
4. Alert Time: 15 minutes
5. Quiet Hours: 22:00 - 07:00
```

## 🚨 Quick Troubleshooting

| Problem | Quick Fix |
|:---|:---|
| Can't login | Check email/password, try reset |
| EPG not loading | Pull down to refresh, check internet |
| No notifications | Settings > Notifications > ON |
| 3D not working | Settings > 3D Effects > OFF |
| App crash | Close & reopen, update app |
| Slow performance | Disable 3D effects |
| Sync issues | Settings > Sync Now |
