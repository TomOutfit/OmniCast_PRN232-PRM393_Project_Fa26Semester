## 1. Bắt đầu nhanh

### 1.1 Đăng ký tài khoản mới

```
1. Truy cập: https://omnicast.vercel.app
2. Click "Đăng ký" / "Sign Up"
3. Điền thông tin:
   - Email: your@email.com
   - Password: ********
   - Full Name: Tên của bạn
4. Click "Tạo tài khoản"
5. Đăng nhập thành công!
```

### 1.2 Đăng nhập lần đầu

```
1. Truy cập: https://omnicast.vercel.app/auth
2. Nhập Email và Password
3. Click "Đăng nhập"
4. (Tùy chọn) Bật "Ghi nhớ đăng nhập"
```

### 1.3 Quy trình 3 bước để bắt đầu

```
Bước 1: Khám phá EPG
   ↓
Bước 2: Thêm chương trình vào Watchlist
   ↓
Bước 3: Bật thông báo để không bỏ lỡ
```

### 2.2 Xem lịch phát sóng (EPG)

```
Cách 1: Click vào tab "Lịch phát hôm nay"
Cách 2: Click vào "Xem tất cả" ở bất kỳ đâu
Cách 3: Sử dụng thanh điều hướng thời gian

Kết quả:
- Danh sách đầy đủ các chương trình
- Badge "LIVE NOW" cho chương trình đang chiếu
- Thời gian bắt đầu và kết thúc
```

### 2.3 Tìm kiếm nâng cao

```
1. Click vào icon 🔍 hoặc tab "Tìm kiếm"
2. Nhập từ khóa (tên chương trình, diễn viên...)

Bộ lọc nâng cao:
├── Thể loại: Drama | Comedy | News | Sports | Movie
├── Ngày: Hôm nay | Ngày mai | Tuần này | Tùy chọn
├── Giờ: Sáng | Trưa | Chiều | Tối | Đêm
├── Kênh: VTV1 | VTV3 | HTV7 | ...
└── Độ tuổi: G | PG | 13+ | 16+ | 18+
```

### 2.4 Thêm vào Watchlist

```
1. Tìm chương trình muốn thêm
2. Click vào icon ❤️ / "Thêm vào Watchlist"
3. Chương trình sẽ xuất hiện trong Watchlist
4. Bạn sẽ nhận thông báo 15 phút trước khi chiếu

Quản lý Watchlist:
- Xem danh sách: Tab "Watchlist"
- Xóa khỏi Watchlist: Click icon ❤️ lần nữa
- Sắp xếp: Theo ngày | Theo kênh | Theo thể loại
```

### 2.5 Xem chi tiết chương trình

## 3. Hướng dẫn Mobile App

### 3.1 Cài đặt APK (Android)

```
Bước 1: Download APK
   → Tải từ website hoặc GitHub Releases
   
Bước 2: Cho phép cài đặt từ nguồn không xác định
   → Settings > Security > Unknown Sources > ON
   
Bước 3: Cài đặt
   → Mở file APK đã tải
   → Click "Cài đặt"
   
Bước 4: Mở app và đăng nhập
   → Đăng nhập như bình thường

### 3.3 Offline Mode

```
Kích hoạt Offline:
1. Settings > Offline Mode > ON
2. Chọn nội dung cần lưu:
   - ✅ Watchlist
   - ✅ EPG 24h
   - ✅ Thông tin kênh
   
Sync khi online:
- Pull to refresh
- Settings > Sync Now
```

### 3.4 Thông báo Native

```
1. Cho phép thông báo
   → Khi đăng nhập lần đầu
   → Settings > Notifications > ON
   
2. Cài đặt thời gian thông báo
   → Settings > Alert Time
   → Chọn: 5 | 10 | 15 | 30 | 60 phút
   
3. Ví dụ thông báo:
   "Này bạn ơi! 'Running Man' bắt đầu rồi nè! 🎬"
```

   - Quick: 5-10 giây
   - Full: 30-60 giây

### 4.3 3D Effects (Web)

```

3. Enable 3D Effects: OFF

Các effect bao gồm:
- Landing: 3D Hero animation
- EPG: Parallax timeline
- Cards: 3D flip on hover
- Detail: 3D poster reveal

## 5. Cài đặt

### 5.1 Profile Settings

```
Truy cập: Click avatar user > Settings > Profile

Có thể thay đổi:
- Full Name
- Email (cần xác nhận)
- Avatar
- Timezone
- Language (Vietnamese/English)
```

### 5.2 Notification Settings

```
Settings > Notifications

Tùy chọn:
├── Enable All Notifications: ON/OFF
├── Reminder Time: [15 phút ▼]
├── Alert Types:
│   ├── 📺 Program Start: ON
│   ├── 🔄 Schedule Change: ON
│   ├── ⭐ Watchlist Update: OFF
│   └── 🎬 New Programs: OFF
└── Quiet Hours: 22:00 - 07:00
```

### 5.3 Display Settings

```
Settings > Display

Tùy chọn:
├── Theme: Light | Dark | System
├── 3D Effects: ON/OFF
├── Compact View: ON/OFF (EPG)
└── Language: Vietnamese | English
```

### 5.4 Security Settings

```
Settings > Security

- Đổi mật khẩu
- Xem thiết bị đã đăng nhập
- Đăng xuất tất cả thiết bị
- Bật 2FA (sắp ra mắt)
```

## 6. Giải đáp nhanh

### Câu hỏi thường gặp

```
Q: Quên mật khẩu?
A: Trang đăng nhập > "Quên mật khẩu" > Nhập email > Reset link

Q: Đăng xuất từ xa?
A: Settings > Security > "Đăng xuất tất cả thiết bị"

Q: Xóa tài khoản?
A: Settings > Account > Delete Account (Admin approval required)

Q: Lịch sử xem ở đâu?
A: Profile > Viewing History

Q: Chia sẻ chương trình?
A: Trang chi tiết > Share icon > Copy link / Social media
```

### Keyboard Shortcuts (Web)

```
Phím tắt          Chức năng
─────────────────────────────────
Ctrl + K           Mở tìm kiếm
Escape             Đóng modal
→ / ←             Chuyển ngày EPG
↑ / ↓             Cuộn EPG
Space              Pause/Play carousel
F                  Fullscreen mode
?                  Hiện help
```

### Troubleshooting

```
Vấn đề                    Giải pháp
─────────────────────────────────────────────────────────────
EPG không load           F5 refresh hoặc Ctrl+F5 hard refresh
3D không hoạt động       Kiểm tra WebGL: webglreport.com
Thông báo không đến      Settings > Notifications > ON
App mobile lag           Settings > Display > 3D Effects: OFF
Sync fail                Thử đăng xuất > đăng nhập lại
```
