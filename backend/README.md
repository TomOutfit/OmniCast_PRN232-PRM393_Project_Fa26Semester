# OmniCast — Backend (API)

Phân hệ dịch vụ Backend Web API cho hệ thống OmniCast.

- **Công nghệ**: NestJS / Node.js (TypeScript), Prisma ORM
- **Cơ sở dữ liệu**: Supabase Cloud PostgreSQL (`https://tktexqtqfnlfynbytjpw.supabase.co`)
- **Triển khai Web API (Vercel / Serverless API)**: [https://omnicast-api.vercel.app](https://omnicast-api.vercel.app)
- **Tài liệu API (Swagger UI / OpenAPI)**: `https://omnicast-api.vercel.app/swagger`
